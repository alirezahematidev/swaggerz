    04Reference

    Programmatic API

    generate(), validate(), loadConfig(), defineConfig() and their types, read from the published declarations.

    The CLI is a thin layer over these functions. Use them to generate from a build script, a test or another tool:

    Everything below is exported from swaggerz and follows semantic versioning, except the types of the intermediate representation and the project model, which areexperimental until 1.0 and may change in minor releases.

    Functions

    defineConfig

    Declares a configuration with full type checking and editor autocomplete.

    definePlugin

    Declares a plugin with full type checking.

    formatDiagnostic

    Formats a diagnostic for terminals: severity, code, message, location, context and hint. Control characters in the diagnostic's text are escaped (see printable).

    generate

    Loads configuration, compiles the specification and writes the generated client. Throws SwaggerzError when the configuration cannot be loaded; all other problems are returned as diagnostics with ok: false.

    loadConfig

    Loads, merges, validates and resolves configuration. Throws SwaggerzError on failure.

    validate

    Validates the configuration and specification and generates in memory without writing.

    Classes

    SwaggerzError

    Thrown when compilation cannot continue. Carries the diagnostics collected so far.
