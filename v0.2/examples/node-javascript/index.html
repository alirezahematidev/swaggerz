    05Project

    Node.js JavaScript example

    A plain JavaScript Node.js script using a client generated as JavaScript with JSDoc and .d.ts declarations from an OpenAPI 3.0 document (openapi.yaml).

    Or, inside this directory once swaggerz is built:

    src/index.js configures the apiKey security scheme and a logging middleware, then creates and lists tasks (with an exploded array query parameter) and handles a 404 with the operation’s error guard, which types the body by status. Editors show the generated types and documentation for every call.

    Expected output:

    src/mocks.js implements the API with the generated Mock Service Worker handlers, generated as JavaScript too: fixtures (makeTask) seed an in-memory list, response functions read the query, the path parameters and the typed request body, check the API key and return the documented 404. setupServer() from msw/node answers the client’s requests inside the process. See mocks.
