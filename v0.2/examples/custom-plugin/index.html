    05Project

    Custom plugin example

    Two small plugins applied to a Swagger 2.0 document (swagger.json):

    • plugins/sdk-names.ts names operations after an x-sdk-name vendor extension (Users_List → listUsers) with the operationName hook. Teams_ListMembers has no extension and keeps the default name, teamsListMembers.
    • plugins/operation-catalog.ts adds a @see link to each operation’s documentation with the jsdoc hook and emits catalog.ts, a typed constant listing every operation, with the generate hook.

    Or, inside this directory once swaggerz is built:

    Plugin files are owned by the generator like built-in files: they are recorded in the manifest and removed when a later run no longer produces them. See docs/plugins.md for every hook.
