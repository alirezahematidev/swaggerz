# Diagnostics

Every problem is reported as a diagnostic with a stable code, a severity, a message, and when available a location (file, JSON pointer, line and column), the operation it relates to and a hint. Codes are stable across patch releases; `--json` output includes them for tooling.

- **error** — generation stops and nothing is written.
- **warning** — output is generated; something was ignored, interpreted or may not match the specification exactly.
- **info** (notes) — shown with `--verbose`.

| Code                                                                                                                                                                                      | Severity      | Meaning                                                                                                                                           |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config/not-found`                                                                                                                                                                        | error         | No config file in the working directory                                                                                                           |
| `config/load-failed`                                                                                                                                                                      | error         | The config file threw or could not be imported                                                                                                    |
| `config/plugin-load-failed`                                                                                                                                                               | error         | A plugin reference (`'./plugin.mjs'`, `'package'` or `['package', options]`) could not be resolved or imported, or did not produce a valid plugin |
| `config/invalid`                                                                                                                                                                          | error         | Unknown option or wrong value (with a suggestion)                                                                                                 |
| `config/unsafe-output`                                                                                                                                                                    | error         | The output directory contains the project, the config or the spec                                                                                 |
| `spec/load-failed`, `spec/parse-error`                                                                                                                                                    | error         | The document could not be read or parsed (with line and column)                                                                                   |
| `spec/not-an-object`, `spec/unknown-format`                                                                                                                                               | error         | Not a Swagger/OpenAPI document                                                                                                                    |
| `spec/unsupported-version`, `spec/invalid-version`                                                                                                                                        | error         | Unsupported or malformed `swagger`/`openapi` field                                                                                                |
| `spec/version-mismatch`                                                                                                                                                                   | error         | The document's version differs from `spec.version`                                                                                                |
| `spec/unquoted-version`                                                                                                                                                                   | warning       | Version given as a YAML number                                                                                                                    |
| `spec/missing-field`                                                                                                                                                                      | error/warning | Required document fields are missing                                                                                                              |
| `spec/invalid-path`, `spec/invalid-operation`, `spec/invalid-parameter(s)`, `spec/invalid-response`, `spec/invalid-security`                                                              | error/warning | Malformed document parts                                                                                                                          |
| `spec/unsupported-dialect`                                                                                                                                                                | warning       | Unknown `jsonSchemaDialect`                                                                                                                       |
| `ref/invalid`, `ref/unresolved`, `ref/missing-target`                                                                                                                                     | error         | A `$ref` is malformed or points nowhere                                                                                                           |
| `ref/circular`, `ref/too-deep`                                                                                                                                                            | error         | A chain of references never reaches a schema                                                                                                      |
| `ref/external-blocked`                                                                                                                                                                    | error         | Blocked by the reference policy (hint explains how to allow it)                                                                                   |
| `ref/external-load-failed`, `ref/too-many-documents`                                                                                                                                      | error         | External document problems                                                                                                                        |
| `schema/invalid`, `schema/invalid-type`, `schema/invalid-discriminator`                                                                                                                   | error         | Malformed schemas                                                                                                                                 |
| `schema/too-deep`                                                                                                                                                                         | error         | Inline nesting beyond 512 levels                                                                                                                  |
| `schema/foreign-keyword`                                                                                                                                                                  | warning       | Keyword from another version, honored                                                                                                             |
| `schema/unsupported-keyword`                                                                                                                                                              | warning       | `$dynamicRef`, `$recursiveRef`, or a 3.1-only keyword (`if`, `dependentSchemas`, …) in a 3.0 document, ignored                                    |
| `schema/assertion-keyword`                                                                                                                                                                | info          | `not`, `if`/`then`/`else`, `dependentSchemas`, `dependentRequired`: not expressible in TypeScript types, enforced by generated Zod schemas        |
| `schema/validation-only-keyword`                                                                                                                                                          | info          | Keyword that only affects validation                                                                                                              |
| `schema/ref-siblings-ignored`, `schema/nullable-31`, `schema/null-type`, `schema/type-array`, `schema/tuple-items`, `schema/exclusive-boolean`                                            | warning       | Version-specific semantics applied                                                                                                                |
| `schema/empty-enum`, `schema/enum-type-mismatch`, `schema/empty-composition`, `schema/discriminator-ignored`                                                                              | warning       | Questionable schemas                                                                                                                              |
| `schema/array-without-items`                                                                                                                                                              | info          | Array elements typed as `unknown`                                                                                                                 |
| `operation/duplicate-id`                                                                                                                                                                  | warning       | Duplicate `operationId`; names are disambiguated                                                                                                  |
| `operation/missing-path-parameter`, `operation/unused-path-parameter`, `operation/optional-path-parameter`                                                                                | warning       | Path template and parameters disagree                                                                                                             |
| `operation/duplicate-parameter`, `operation/multiple-bodies`, `operation/body-and-form`                                                                                                   | error         | Invalid parameter combinations                                                                                                                    |
| `operation/invalid-status`, `operation/invalid-style`, `operation/invalid-collection-format`, `operation/empty-request-body`, `operation/file-without-multipart`, `operation/body-on-get` | warning       | Ignored or adjusted operation parts                                                                                                               |
| `operation/ignored-header`                                                                                                                                                                | info          | `Accept`, `Content-Type` or `Authorization` header parameter ignored, as OpenAPI 3 requires                                                       |
| `security/invalid-scheme`, `security/unknown-scheme`                                                                                                                                      | error/warning | Security problems                                                                                                                                 |
| `naming/collision`                                                                                                                                                                        | warning       | A name was taken; a suffix was added                                                                                                              |
| `react-query/invalid-page-param`                                                                                                                                                          | error         | The configured infinite query parameter does not exist                                                                                            |
| `output/user-file`                                                                                                                                                                        | error         | A file the generator does not own is in the way                                                                                                   |
| `output/edited-stale-file`, `output/edited-file-kept`                                                                                                                                     | warning       | Hand-edited generated files were kept                                                                                                             |
| `output/invalid-path`, `output/duplicate-path`                                                                                                                                            | error         | A plugin produced an unsafe or duplicate path                                                                                                     |
| `output/write-failed`                                                                                                                                                                     | error         | Writing failed (the previous output is intact)                                                                                                    |
| `plugin/hook-failed`                                                                                                                                                                      | error         | A plugin hook threw                                                                                                                               |
| `dashboard/network-access`                                                                                                                                                                | error         | The dashboard was asked to listen on a non-loopback interface                                                                                     |
| `internal/error`                                                                                                                                                                          | error         | Unexpected failure; please report it                                                                                                              |
